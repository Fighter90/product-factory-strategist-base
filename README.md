# База методических знаний — Стратег Фабрики продуктов

Публичный репозиторий **постоянных методических знаний** агента: как проводить исследование,
ставить цели, строить стратегию, проверять результат. Знания не зависят от конкретного проекта
и не меняются в ходе работы над задачей.

## Как устроена база

| Папка | Что внутри | Кто меняет |
|---|---|---|
| `methods/` | 111 методических карт RU (одна карта = один метод/тема: frontmatter с тегами и связями `[[...]]`, разделы метода) | Методолог, через PR |
| `methods_en/` | 111 EN-зеркал: тот же id, `lang: en`, то же имя файла | Методолог, через PR |
| `templates/` | Шаблоны выходных документов: ситуация, варианты, продуктовая и коммс-стратегии, план проверки (включая KPI-таблицу двух плоскостей), six-pager PROMPT + эталон-конспект (RU/EN) | Методолог, через PR |
| `rubrics/` | Критерии качества — по ним агент и субагент-оценщик проверяют результат | Методолог, через PR |
| `INDEX.md` · `INDEX_EN.md` | Навигация: какая карта нужна на каком шаге 12-шагового процесса | `python3 -m tools.pfs kb index` |
| `inbox/external-methodology/` | Описание процесса дистилляции: как внешние источники превращаются в карты | Методолог, через PR |

## Как карты создаются

1. **Внешние источники:** методологические материалы (курсы, книги, публичные отчёты) собираются в инбокс.
2. **Дистилляция:** методолог выделяет метод как отдельную карту — frontmatter (`id`, `lang`, `tags`, `related`),
   разделы метода, критерии качества.
3. **Паритет RU/EN:** каждая карта существует в двух зеркалах с одинаковым id и содержанием.
4. **Lint:** `python3 -m tools.pfs kb lint` проверяет frontmatter, имена файлов, `[[ссылки]]`, дубли тегов,
   пустые разделы и паритет RU/EN по разделам и объёму.

## Как база используется агентом

- **Установка:** `scripts/install.sh` (репозиторий `-agent`) клонирует базу в `knowledge/` внутри репозитория агента
  (`knowledge/` в .gitignore агента — контент живёт здесь).
- **Доступ из агента:** `pfs kb search "запрос"` — поиск, `pfs kb show <id>` — карта, `pfs kb index` — навигация.
- **Привязка к шагам:** каждая карта привязана к шагу 12-шагового процесса (`pfs step` печатает «Карты шага»).
- **Контракт качества:** рубрики (`rubrics/`) — то, по чему комитет и субагент-оценщик принимают работу.
