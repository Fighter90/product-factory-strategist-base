# Входящие: материалы внешних источников (дистилляция в базу знаний)

Источник: личные учебные материалы (лекции, семинары, ДЗ, проекты).
Задача исполнителя — **дистилляция методологии** в карты `knowledge/methods/` (RU)
и `knowledge/methods_en/` (EN-зеркала), без брендов (университеты, вузы,
преподаватели, компании-заказчики, названия продуктов заказчиков — запрещены).

Формат карточек — как у существующих `M-*.md` (смотри 2–3 соседних карты).
Валидация: `python3 -m tools.pfs kb lint` (из корня репозитория агента).
Индекс: `python3 -m tools.pfs kb index` после добавления карт.

Инвентарь исходников — INVENTORY.md (файлы лежат у владельца, не в репо;
для чтения конкретного файла запроси его у владельца или работай по md/txt,
которые уже были сконвертированы в `_extracted/` если там есть содержимое).

Порядок работы (пакет 1 — продуктовое ядро, ближе всего к существующей базе):
1. Продуктовый менеджмент
2. Методы исследования продуктовых гипотез
3. Продуктовые бизнес-модели и юнит-экономика
4. Пользовательский опыт и управление клиентскими метриками
5. Анализ рынка ИТ продуктов
6. Продуктовая разработка / Быстрое создание MVP в Data Science

Правила:
- одна карта = один метод/тема (не «курс»); имя файла = id карты
- сначала RU-карта, затем EN-зеркало (та же структура, ≥80% объёма)
- в карточке: суть метода, когда применять, шаги, критерии качества, типовые ошибки
- не дублируй существующие карты (сначала `pfs kb search` по теме)
- коммит и push — прямо в `main` этого репозитория (он приватный)
