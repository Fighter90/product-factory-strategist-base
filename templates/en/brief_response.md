## Part 2 · Customer problem analysis
- Восстановленный случай: последний момент норм → сигнал → кому обратился → что сделал → когда разрешилось → последствие → последний момент помощи. Истории нет — реконструкция с помеченными допущениями + «что спросим и какие записи восстановят ход».
- Различение сигнала и причины (версии → разные действия).
- Причины отставания заказчика (приток / действие / удержание) — предположение + проверка.
- Сопоставление с серьёзной альтернативой: у скольких / как часто / тяжесть / доля случаев с вовремя возможной помощью; какой ущерб важнее.
- Подбор сведений: рассказ клиента, учёт обращений, не обратившиеся; период; повторные ≠ новые.
- Проверяемое предположение: действие → результат; наблюдение для смены приоритета; допущения; диапазон вместо прогноза.

## Part 3 · Offer and path to the customer
- Услуга глазами пользователя: момент → что видит → действие → как узнает, что решено. Обещание + тарифы + чьё согласие.
- Весь путь для КАЖДОЙ роли (приглашение без ответа / отказ / отзыв).
- Одна операция до конца (условия → шаги → где виден итог; повторное нажатие ≠ второй список).
- Почему выберет этот способ: сравнение с привычными; какой шаг исчезнет; насколько раньше вмешаться.
- Состав первого запуска: есть / добавить / без чего обойтись; тариф vs отдельно.
- Проверка удобства: одна задача двумя способами; порядок участников менять; подсказки/ошибки/время; платная — цена при бесплатной альтернативе.
- Что пригодится второй группе / что проверять заново.
- Привлечение: два рынка (весь/доступное/достижимое; доли от баз заказчика); кому подходит первый сценарий; способы → момент/охват/доля; допущения подписаны; шаги остановки.
- Сведение чисел: начало + новые − выбывшие; один способ на подключение; вклад = факт − обычное; CAC канала. Не приписывать инициативе весь прирост.
- Активность: из какого числа подключённых; доля действия; часть роста от групп, часть от доли; «срабатывает само» — польза даже при реже открывающих.

## Part 4 · Customer benefit and operator profit
- Один главный результат + признак наступления (открытие ≠ результат; нужна запись факта).
- Таблица: польза / работа услуги / нежелательные последствия (+ уточнения).
- Единица счёта; числитель/знаменатель; период; воспроизводимость; неизвестный итог отдельно.
- Порог и способ расчёта до запуска; диапазон совместимый с пользой и нулём = данных недостаточно.
- Сравнение с более простым способом (когда оправдан дорогой).
- Пробный запуск: кого включать / с чем сравнивать / что считать / хватит ли времени / действия по результату.
- Прибыль: база → + доп. оплаченные месяцы × ставка → − новые прямые расходы; скольким номерам и в каком месяце доступна услуга; разницы по месяцам планового года.
- Удержание: почему влияет; проверка по платежам; наблюдение после выхода из группы.
- Другие пути денег: экономия поддержки = действительно исчезающие затраты; высвободившееся время — отдельно.
- Граница решения: формула; при слабом спросе/удержании/стоимости; неизвестная цена → формула + значение к узнаванию.
- Окупаемость разработки отдельно; предельная сумма вложений; деньги после планового года → следующие годы.
- Долгосрочный прогноз: группы одинакового размера; Σ(прибыль × вероятность остаться); условный расчёт при нехватке данных.

## Part 5 · Choice, quarterly plan, resources, risks, ask
- Сравнение с двумя другими путями (одна ситуация, один горизонт): польза/клиенты/затраты/срок/последствия ошибки; что оправдает переход к дорогому; самая короткая проверка.
- План по кварталам: что станет известно → какое решение.
- Прогноз по всем строкам таблицы заказчика (основной/неблагоприятный); разрывы недостижимых целей: величина/цена/решение.
- Ориентир на конец 3-го года: числитель/база/условие; возможность первого года; данные до расширения.
- Ресурсы: кто/известно/решить; ответственный+срок старт-зависимых; одновременность/последовательность; недоступность системы → что выполнимо и как меняется прогноз.
- Риски при отклонении: признак/последствия/ответственный/действие; подтверждение исправления.
- Конкретная просьба: решение сейчас, люди/деньги, ответственный; что руководство увидит к следующей точке; минимальный объём финансирования.
